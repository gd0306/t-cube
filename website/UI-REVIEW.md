# T-Cube 官网独立 UI 审查

目标：`website/index.html`，https://www.gd306.cn/t-cube/ 。模式 Persuade。A（设计）与 B（检测器／浏览器证据）为两个隔离代理；A 在读取 B 结果前完成。评审针对改版前的 a7973dd 页面。

## 设计判断

真实原生渲染与 UI 截图建立了产品辨识度，但结构与语言仍可被其他软件直接复用。AI 痕迹主要来自贯穿近黑背景、重复两句式情绪标题、大留白和相似左右图文节奏，不能凭此断定页面的生成来源。

## Priority Issues

1. P1：近黑贯穿使玻璃暗部轮廓弱，也违背用户明确要求。改为深海蓝光场首屏和浅冰蓝正文交替，少数产品展台保留深蓝，避免全页泛紫渐变。
2. P1：连续对偶标题和“顺手/灵感/从容”泛词削弱识别。保留主品牌句，其他标题直接说明六面入口、材质、贴边行为、剪贴板和平台功能；合并 intro 的双层标题。
3. P1：持续运动感不足，空间效果仅有一次进入和轻微指针倾斜。围绕立方体设计缓慢漂浮、折射光场，提供暂停，后台和离屏停止、减少动态时静态，不添加粒子雨或无关数字。
4. P2：多个区段120–140px留白和同构左右图文造成中段低谷。压缩相关内容间距，强化截图近景、产品展台和规格列表的差异。
5. P2：重复原生图注、向下提示、录制说明和承托块增加碎片。删除不必要提示；必要安装、平台与隐私边界集中留在系统要求和 FAQ。移动页首按钮提升到44px触控高度。

首次访问者需要在副标题立刻看到“3D 桌面启动器”；手机用户需要更少重复滚动；审慎下载者仍需保留真实兼容和安全边界。

## 检测证据

静态检测器成功运行，13条 cramped-padding warning（material/clipboard/privacy/download 与 details/FAQ 包装层）。实际子元素提供内距，浏览器 overlay 成功注入并运行，报告0项命中。没有为静态误报盲目增加padding。旧页320/390/1440均无页面横向滚动；采样文字对比达到4.5:1。细节和全部证据见 `.build/website/review-b/`，A 的独立截图见 `.build/website/review-a/`。

Questions skipped: 用户已明确授权去除 AI 痕迹并优化，且追加明确背景、动态效果和删除多余提示的方向；沿用已授权范围执行。

## 已实施的优化

- 将近黑底改为深蓝光学首屏、浅冰蓝正文与少量深蓝产品展台，保留真实原生截图。
- 合并 intro 双层标题，改用具体功能名，删去24条未使用的提示/重复文案；移除向下提示、原生图注、重复安装说明和统一截图承托块。
- 压缩相关章节间距；截图按真实比例放大，平台要求和完整 FAQ 保留。
- 为首屏增加漂浮立方体、低幅折射光线与跟随指针的光场，所有循环可暂停并记住选择。离屏/文档隐藏自动暂停，减少动态效果使用静态画面。手机画布降到20fps、像素密度上限1，桌面上限30fps/1.5。
- 移动页首触控区提升到至少44px；中英文文案、下载数据刷新与原生弹窗保留。

## 验证

- 本地中英两种语言 × 320/390/768/1024/1440 的10种视口组合通过，无页面横向溢出；光场自身的出血被舞台裁切。
- 语言记忆、键盘材质切换、图例/动效对话框与 Escape、功能详情、图片、减少动态效果均通过，无 JavaScript page errors。
- 通过画布前后帧核对持续运动、暂停后不变、暂停选择重载记忆、离屏暂停和回屏恢复、减少动态时静态，以及动效按钮中英标签。
- 正文对比度抽查约 4.89–5.87:1，均超过4.5:1；该抽查不等于所有渐变像素与全部浏览器的证明。
- 版本数据更新的非法主机拒绝、不完整发布回退、模拟下一版本 HTML/JSON 更新继续通过。
- 这是基于旧页27/36评审的定向修复，没有把修改后的页面宣称为重新评分后的满分。
