# Clipboard history prototype

**Goal:** Add an opt-in local text clipboard history on both platforms, integrated next to the existing common-content library, and install the verified build on the maintainer Mac.

**Scope decision:** User asked to try clipboard history. First version is memory-only, disabled at each application launch, with explicit enable/pause UI. History is not included in backup/export and is cleared on exit. No extra permission prompt to implement; actual monitoring remains user's explicit UI choice.

**Behavior contract:** Latest-first, exact-text deduplication promotes an existing entry. Keep at most100 entries,64 KiB UTF-8 per item and2 MiB UTF-8 text total. Preserve original whitespace for accepted text; skip blank, NUL-containing and oversize text without truncation. Delete one/clear all/search. Copy or paste via existing focus-checked path; allow explicitly saving a history entry as an ordinary library snippet. Skip self-generated copies. On enable/resume, establish current clipboard sequence without ingesting previously copied text. Default poll interval500 ms; inspect sequence before reading content; no background file writes or network.

**Native policy:** macOS skips org.nspasteboard.ConcealedType/TransientType/AutoGeneratedType and fileURL-marked pasteboards; Windows skips explicit clipboard-history/monitor exclusion formats (verify documented policy), file-drop formats and app-generated writes. Guards are best-effort, not a guarantee of identifying every secret. UI explains memory-only storage, opt-in and pause.

- [x] macOS core bounded history, injected native recorder, opt-in/search/delete/clear/copy/paste/save UI within library window, timer lifecycle and regression tests.
- [x] Windows bounded model/recorder, IPC role validation, matching UI, native format policy, tests and isolated native smoke.
- [x] Independent review, full tests/builds and native UI verification with recording left OFF on maintainer data.
- [x] Version/install preserving application and raw user JSON backups; record verification and limitations.

No user clipboard contents in diagnostics. Tests use fake clipboard readers or uniquely named test pasteboards; use temporary stores for saving snippets. Preserve existing common-content/template behavior and drafts. No persistence/encryption/cloud sync/image history in this prototype.
