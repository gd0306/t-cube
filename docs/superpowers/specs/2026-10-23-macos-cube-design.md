# T-Cube macOS 首版设计

状态：用户于 2026-10-23 确认整体方案；外观采用深灰磨砂，预留主题扩展。

## 产品与范围

T-Cube 是原生 macOS 桌面立体启动器。一个透明背景、无标题栏、始终置顶的小立方体承载六个分组，每面四个入口，支持本地应用和文件夹。只保存本地快捷入口，不移动、复制或删除用户文件。

首版最低 macOS 15。使用 Swift、AppKit、SwiftUI 和 RealityKit，无第三方运行依赖。提供可以直接启动的本地 `.app` 和可在 Xcode 打开的 Swift Package。

## 用户已确认的交互

- 六面六分组，分组名称可修改，每面采用 2×2 排列。
- 鼠标按住拖动自由旋转，松手后最近的面自动转正。
- 静止时单击正面图标启动应用或在 Finder 打开文件夹。
- 拖动超过阈值后，即使回到起点也不得触发点击。
- Option＋拖动移动整个悬浮窗口。
- 从 Finder 拖入应用或文件夹，加入正面分组；无空位时明确提示，不覆盖已有入口。
- 右键打开编辑窗口，允许分组改名、添加、排序、移除入口。
- 菜单栏提供显示／隐藏、编辑、尺寸调整和退出。
- 自动保存分组、入口、尺寸和窗口位置。

## 显示与窗口

默认深灰磨砂机身、轻微圆角、柔和边缘高光、真实应用图标。面标题和名称清晰可读。静止采用轻微透视展示立体感，吸附到选定面的统一正向朝向，防止图标倒置。旋转／吸附期间禁止启动入口。

面板位于常规应用窗口之上，切换应用后继续显示，操作立方体尽量不夺走键盘焦点。首版不承诺覆盖系统安全界面或所有独占全屏窗口。窗口尺寸限制在适合桌面小组件的范围；恢复位置时夹紧到当前屏幕可见区域，兼容外接屏断开。

面板之外不设整屏透明窗口。立方体四周透明区域的鼠标命中与穿透必须在真机检查，避免占用过多桌面区域。

## 内容与编辑

默认分组为常用、开发、设计、办公、文件夹、更多，初次运行为空。空槽显示添加符号并可点击选择文件。应用和文件夹可以混放；普通文件暂不接收。同组重复入口拒绝，跨组允许。批量拖入逐项处理，汇总未添加原因。

编辑窗口使用原生控件，显示六个分组和各自四个槽位，提供选择器添加、上下移动、移除。移除仅删除快捷入口。入口失效时显示可读错误，并可从编辑窗口重新选择目标。

## 架构

- `CubeCore`：分组与入口模型、配置校验、JSON 原子保存、四元数旋转和最近面判断、拖动阈值判断。核心独立于 UI，使用 Swift Testing。
- `TCube`：AppKit 应用生命周期、菜单栏、透明置顶 `NSPanel`、事件分发、RealityKit 场景、SwiftUI 编辑窗口。
- `CubeTheme`：集中管理机身、面板、文字、高光颜色及表面参数。首版仅 graphite；后续海洋、星空、花海等主题通过扩展主题定义与资源加入，不在本次加入空白主题选项。
- `LauncherService`：验证入口类型、生成本地 URL bookmark、解析目标、读取系统图标、调用 NSWorkspace 打开目标。

每个面绘制为高分辨率纹理，图标与立方体共同旋转；点击通过场景命中／面内坐标定位槽位。视觉更新只在交互或内容变更时触发，不加持续自转、粒子或动态背景。

## 数据与错误

配置保存在用户 Application Support/T-Cube 目录，包含版本、六个分组的入口、主题 ID、尺寸和位置。入口保存 URL、名称、类型和 bookmark。保存采用原子替换。不存在配置时创建空模型；读取损坏配置时保留原文件并明确提示，不静默覆盖。文件访问、启动失败、添加不支持内容、分组满员均应显示可理解的反馈。

## 验证与交付

自动验证：六面可达、吸附后图标朝向、拖动不误触、满员和重复处理、排序与移除、配置往返／损坏保护。实际构建并运行 `.app`，检查透明、置顶、旋转、菜单和编辑窗口。无法通过工具完成的桌面操作明确列出，不将编译成功视为体验已经验收。
