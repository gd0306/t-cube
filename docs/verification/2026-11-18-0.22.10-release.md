# 0.22.10 后台内存与 Ctrl 长按修复

## 修复与回归

- macOS `0.22.10` build `53`；Windows 同步为 `0.22.10`。后台内存与 Ctrl 修复针对 macOS 原生客户端。
- 隐藏或完全遮挡期间只保留一份待应用的主题更新，重新显示时读取当前主题并更新图形资源。覆盖轮换回到原已应用主题的情况。保留可见主题切换、静帧恢复和用户配置。
- 同步发布此前本机安装的 Ctrl 事件计数延迟修复，见[诊断与验证](2026-11-14-control-hold-counter-lag.md)。
- 新的隐藏主题更新测试在旧实现上失败，修复后 `50` 项聚焦原生与核心测试通过。覆盖隐藏／遮挡更新、无输入自动恢复、重新显示、原主题回绕、静帧／切换生命周期与 Ctrl 组合输入门禁。
- 相同临时配置、隐藏窗口、`180` 次主题更新的加速实验：修复前 `86.6 → 338.9 MiB`；修复后 `88.6 → 86.0 MiB`，后段稳定，峰值约 `92.3 MiB`。这是受控短时实验，不等于连续多日或所有界面场景的内存保证。

```bash
swift test --scratch-path .build/tests --no-parallel --filter 'ThemePresentationLifecycle|RenderingLifecycle|ThemeCycle|PreparedThemeFrame|ControlHold'
env TCUBE_BACKGROUND_MEMORY_PROBE=1 TCUBE_MEMORY_PROFILE_OUTPUT=/absolute/background-after.json \
  swift test --scratch-path .build/tests --no-parallel --filter BackgroundThemeMemoryProbeTests
```
