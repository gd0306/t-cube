# T-Cube 0.15.0 release verification

Release source: `7b02bf8d612687777a685ffa9541e5a110b762cd`.

Release: https://github.com/gd0306/t-cube/releases/tag/v0.15.0

## Behavior

Windows now shares the native macOS material model: glass is the default, slime is independently selectable, and all nine themes/custom colors/automatic cycling preserve the material. Slime uses native cursor samples, spring deformation and analytic normals; launcher decals remain rigid. Leaving the widget rebounds to rest, switching to glass restores the original geometry, and the Windows animation preference disables deformation.

Existing Windows native left-drag movement, right-drag rotation, Ctrl resize/drag, application discovery, launch shortcuts, settings, placement and four-icon expansion remain covered by installed-runtime tests.

## Automated checks

- `swift test --scratch-path .build/tests`: native event-queue, application and core tests passed. Opt-in render exports are skipped in the normal run.
- Windows Node 22: `npm run typecheck`, `npm test`, and `npm run build` passed locally. The local test run had 85 passing cases and one Windows-only case skipped.
- [Windows source-client workflow](https://github.com/gd0306/t-cube/actions/runs/40549893795): both `windows-2022` and `windows-2025` passed type checking, tests, build, isolated source installation and native desktop smoke checks.
- [Windows installer workflow](https://github.com/gd0306/t-cube/actions/runs/40549955560): generated the x64 NSIS installer, installed the actual executable in an isolated directory, verified packaged Koffi dependencies and ran the complete native interaction suite against that installed application. The suite also toggled and restored the real Windows animation preference.
- `bash scripts/build-dmg.sh` and `bash scripts/verify-dmg.sh` ran from an archive of the exact release source. DMG checksum, mounted app/executable, ad-hoc signature, Applications link and installation note passed. Packaging did not replace the running local application.
- `git diff --check` passed before the release source was committed.

The smoke tests use temporary configuration stores and restore their native input/animation fixtures. Windows desktop verification ran on GitHub-hosted runners; this is not a manual test on a physical Windows PC. Windows screenshots were inspected for the material selector and slime shell/icon appearance.
