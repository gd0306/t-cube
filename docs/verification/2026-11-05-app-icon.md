## Reproduction and formats

Run from the repository on macOS:

```bash
swift scripts/make-icon.swift .build/AppIcon.iconset --sync-assets
```

The regular app build generates only the macOS iconset. The explicit sync option also updates the checked-in Windows and README assets from the same master, preserving the existing PNG dimensions. There is no image-generation service or new dependency required to build the application.

- macOS:10 PNG representations from16 to1024 physical pixels, including Retina slots, packed as `AppIcon.icns`.
- Windows:512px PNG and PNG-backed ICO frames16,32,48,64,128,256, with alpha.
- README:256px PNG, displayed by the unchanged96px bilingual brand header.

Apple ImageIO independently decoded all6 ICO and10 ICNS frames. Exact dimensions, offsets/lengths and 256px directory encoding were checked in review. Regeneration was byte-reproducible, including from another working directory. The approved source,16/32px legibility,256px documentation image and installed IconServices rendering were visually inspected. The macOS/Windows launcher itself is unchanged.
