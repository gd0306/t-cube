# Approved monochrome application icon — 0.22.1

The maintainer selected the white rounded-square icon with three black rounded cube faces and central negative space. `Resources/AppIcon.png` is byte-identical to that approved proposal (1254×1254 RGBA); no further redesign or geometric edits were applied. Master SHA256: `c1c75ff6111f279adbde4ce8c4caf9bd0b6323053c3f697cf8fe6912b3de695b`.

## Reproduction and formats

Run from the repository on macOS:

```bash
swift scripts/make-icon.swift .build/AppIcon.iconset --sync-assets
```

The regular app build generates only the macOS iconset. The explicit sync option also updates the checked-in Windows and README assets from the same master, preserving the existing PNG dimensions. There is no image-generation service or new dependency required to build the application.

- macOS: 10 PNG representations from 16 to 1024 physical pixels, including Retina slots, packed as `AppIcon.icns`.
- Windows: 512px PNG and PNG-backed ICO frames 16,32,48,64,128,256, with alpha.
- README: 256px PNG, displayed by the unchanged 96px bilingual brand header.

Apple ImageIO independently decoded all 6 ICO and 10 ICNS frames. Exact dimensions, offsets/lengths and 256px directory encoding were checked in review. Regeneration was byte-reproducible, including from another working directory. The approved source, 16/32px legibility, 256px documentation image and installed IconServices rendering were visually inspected. The macOS/Windows launcher itself is unchanged.
