# T-Cube 0.1 本地开发版验证记录

日期：2026-10-23。环境：Apple Silicon，macOS 27.0.1，Xcode 27.0，Swift 6.4。源码最低部署目标为 macOS 15；实际测试环境仅为上述机器。

## 已执行

- 最终 `swift test --scratch-path .build/tests` 返回 0：20 项 Swift Testing 测试通过，0 失败。协调者独立复跑时间为 22:15:54。
- 最终 `bash scripts/build-app.sh` 返回 0，生成 release `build/T-Cube.app`。Swift 编译输出无警告；应用为 arm64 本地开发构建。
- `plutil -lint build/T-Cube.app/Contents/Info.plist`、`codesign --verify --strict build/T-Cube.app`、`git diff --check` 返回 0。
- 首次启动和最终修正后重新启动均获得 T-Cube 运行窗口；最终截图显示深灰表面、正向中文标题、四个空入口和立体透视。
- 核心模型审查通过；最终全量审查发现两处交互错误，修正后进行了定向复审，两项均判定已解决，无新增实质问题。

## 修正与回归

1. 指定空槽添加／重新选择目标曾调用排序操作，导致无关图标移动。现在使用验证后的精确位置放置；五项新增测试覆盖稀疏插入、稀疏替换、重复替换保持原数据、占用位置拒绝以及无效参数保持原数据。
2. 原生 ARView 点击曾额外翻转 Y 坐标。真实 AppKit/RealityKit 诊断确认 `isFlipped=false` 时，世界上方点投影到 `(175, 238.134)`，直接命中成功，翻转后命中失败。两个点击／穿透命中路径现均使用原生局部坐标。此诊断验证框架坐标契约，不替代真实鼠标点选验收。

现有测试还覆盖六面朝向与吸附、拖动阈值保持、分组容量与重复、配置往返与损坏保护、屏幕位置夹紧、本地目录／应用／普通文件分类以及纹理槽位几何。

## 尚需手动验收

自动化工具针对非激活悬浮面板的点击与拖动返回 `AXError.notImplemented`。窗口截图与启动可用，原生鼠标交互无法由当前工具执行，因此以下项目尚未完整验收：

- 六个面的实际拖动手感、吸附过程、Option 移动和真实图标点选。
- Finder 拖入、选择器添加、编辑窗口操作以及真实应用／文件夹启动。
- 不同底层窗口下的透明合成、边缘鼠标穿透、切换应用后的置顶与焦点保持。
- 菜单栏隐藏／显示／调整尺寸，以及真实修改配置后退出重启的完整使用流程。

上述内容已经实现，但不将“编译和单元测试通过”等同于“交互验收完成”。多屏、全屏、不同 macOS 版本和 Intel 构建也未做实机验收。
