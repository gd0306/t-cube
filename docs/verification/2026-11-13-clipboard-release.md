# 0.22.9 剪贴板工具、磨砂与拖动修复

## 产品行为

- macOS Ctrl 快捷面板统一采用 NSVisualEffectView 的 popover 磨砂材质和轻微底色，不再使用通透 Clear Glass；Windows 11 22H2+ 使用原生 Acrylic，旧系统使用有底色的实色回退，避免透明窗口。
- Mac 标题区域用原生 `performDrag(with:)` 移动无边框面板；Windows 标题配置原生 draggable region。关闭按钮明确排除在拖动区外，正文的选择、编辑、复制不承担拖动职责。
- 每次长按 Ctrl 唤起均回到历史列表，包括上次留在预览／结果编辑／原文编辑或窗口仍可见的情况；清除未保存草稿，不修改已有记录与系统剪贴板。
- 新增逐条纯文本、空白整理、大小写、JSON 格式化／压缩、URL 参数值编解码。全部先校验再预览，用户决定复制，或编辑结果后复制／保存到本条记录。保留 ID、时间、顺序及自写抑制。
- 不适用的源内容直接提示，不进入失效预览。无变化、无需 URL 编解码、已符合 JSON 格式及可能再次编码 `%XX` 均给出说明。普通文字可作为 URL 参数值编码，不要求是完整网址。
- JSON 只改标记间空白，不改变大整数、重复键或字符串转义；输入输出 64 KiB、JSON 嵌套最多 128 层。错误、空结果、NUL 或非法 UTF-8 不写剪贴板，不截断结果。
- 规则处理全部本地完成，无 AI 请求、API key、历史上传或持久化格式变化。

## 本地验证

- 定向 macOS：43 项应用回归、31 项核心回归通过，覆盖拖动区域命中／关闭排除、原生拖动事件转交、磨砂材质、450px 小屏、再次唤起重置、预校验及原记录／剪贴板保护。
- Windows：类型检查、构建及隔离界面测试通过；本机 288 项单元测试，285 通过、3 项平台相关跳过。浏览器覆盖 380×520／420×540 快捷面板、800×560／920×680 完整历史、深浅色、原生拖动样式、预览与再次唤起。
- Windows 原生烟测增加真实 SendInput 标题拖动、原生菜单选择、预览后新一次 Ctrl 唤起返回列表和明确保存结果的检查。
- 完整 macOS 串行套件未全绿：XCTest 16 项（2 项跳过）有 13 个断言失败；Swift Testing 应用组有一项贴边循环测试产生 30 个几何断言失败，核心 147 项通过。失败在未修改的 EdgeDockAnimation／DesktopAutoHideCoordinator 测试内，包括既有渲染休眠及当前屏幕的半像素坐标对齐。
- 单独 AppKit 最小复现（不依赖 T-Cube 修改）显示：请求 `(24, 390.5, 164, 164)` 时 NSPanel 实际 frame 为 `(24, 390, 164, 165)`，解释新增的几何严格相等失败。未降低断言或修改无关贴边逻辑；不能将专项通过称作全量通过。
- 原生渲染采集使用独立命名剪贴板和合成文本，不注入用户系统剪贴板。Windows 浏览器渲染不等同于 Windows 11 桌面的人工材质验收。
