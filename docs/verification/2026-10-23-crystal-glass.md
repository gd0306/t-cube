# T-Cube 0.3 钻石星点玻璃版

用户要求将外观改为钻石、星点、玻璃风格，并改为右键拖拽移动、滚轮转动。

## 实现

- 默认窗口 164×164 点，移除底部把手与旧线框。六个面和已有应用／文件夹入口继续沿用。
- 使用 12 个边缘切面、8 个三角角切面、半透明棱面材质、38 个有深度的星点和六面四角星高光。透明面不写入深度，允许看到内部星点。视觉组件不参与命中检测。
- 左键只点击入口；左键拖动会抑制误点击，不再旋转或移动。
- 右键按下不打开编辑。超过拖动阈值后移动窗口，松开时夹紧到屏幕可见范围并原子保存位置；未拖动的右键单击在松开后打开编辑。
- 滚轮带吸附动画依次切换全部六面，普通垂直滚轮即可到达顶面和底面。触控板位移累积、切换间隔和惯性过滤用于减少连翻。
- 切面动画可取消并从当前朝向重新开始，避免旧动画覆盖新目标。入口启动在吸附过程中禁用。

## 验证

- TDD 失败基线明确暴露旧行为：右键按下立即编辑、右键拖动不移动、左键拖动仍旋转；三项原生测试共记录七个失败断言。滚轮新 API 也先记录缺失失败。
- 最终 `swift test --scratch-path .build/tests` 在 23:19:14 返回 0：23 项核心测试与 4 项原生界面测试通过，共 27 项。
- 原生测试直接调用真实 CubeView／NSPanel 的右键事件，验证窗口位置、拖动期间命中保护、拖动不误触编辑以及保存后的 JSON。每个测试使用独立临时配置，不改动用户配置。
- `bash scripts/build-app.sh` 生成 0.3.0 release 应用；plist、严格签名验证和 `git diff --check` 均通过。
- 最终应用已实际启动，328×328 Retina 像素截图中可见半透明玻璃、宽切面棱光、内部星点和正面入口，没有旧把手与交叉背面线框。
- 独立代码审查通过，检查了拖动坐标、.84 面坐标归一化、碰撞先后、切面法线／绕序及动画取消。

## 限制

自动化工具对非激活面板的实际滚动返回 `AXError.notImplemented`。原生事件处理和滚轮状态机已有测试，实际鼠标／触控板手感、各桌面背景和不同显示器仍需手动验收。玻璃为透明材质、切面高光与星点视觉，不读取桌面图像，也不声称实现桌面真实折射。
