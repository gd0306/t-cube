# 0.22.11 贴边过渡渲染修复

## 修复与回归

- macOS `0.22.11` build `54`，Windows 同步为 `0.22.11`。本次产品行为修复针对 macOS。
- 贴边展开时，真实窗口会在合成动画结束前以低透明度重新显示。窗口可见通知可能提前恢复 3D 渲染，导致过渡期间出现额外图形工作。
- `CubeSurfaceView` 显式记录贴边过渡状态，过渡期间阻止可见通知和延迟输入恢复渲染。`DesktopAutoHideCoordinator` 在合成动画开始时挂起，在完成、取消或停止时解除；保留原窗口位置、主题更新和用户配置。
- 修复前完整套件再次复现旧停靠测试的 `6` 处断言失败。新增回归 `testRevealCannotResumeRendererBeforeCompositorHandoff` 在旧实现上出现 `3` 处预期断言失败，修复后整个停靠动画组 `7` 项中 `6` 通过、`1` 项按需导出跳过，零失败。
- 完整命令 `TCUBE_BACKGROUND_MEMORY_PROBE=1 swift test --scratch-path .build/tests --no-parallel` 通过：XCTest `17` 项中 `15` 通过、`2` 项按需导出跳过；原生 Swift Testing `239` 项中 `223` 通过、`16` 项按需导出／硬件等检查跳过；核心 `148` 项通过。全部零失败，包含后台内存探针。此前完整套件的停靠动画断言失败已消除。
- 独立只读代码评审未发现 Critical／Important 问题；macOS Release 构建、DMG 只读挂载、包内可执行文件／元数据比对与签名校验通过。
- 本次完整回归中的后台内存探针：隐藏起点 `89.2 MiB`，`180` 次主题切换后与静置后均约 `86.8 MiB`。这是受控短时实验，不代表连续多日或所有界面场景的保证。
