# 0.22.5 默认行为与 Ctrl 计时验收

## 版本与行为

- macOS 源码及本地应用为 `0.22.5`（build `47`），Windows package 与 lockfile 同为 `0.22.5`。已发布的下载仍为 `0.22.4`，未新建发布或改写旧安装包链接。
- 两个平台每次启动默认记录新复制的内容，可暂停当前会话；不导入启动前的旧剪贴板。记录仍只存在当前进程内存中，退出清除。
- 安装版首次启动默认尝试开启登录项。设置中显式关闭会持久保存，不会在下一次启动强行重开；系统撤权、批准要求和注册错误按实际状态处理。macOS 新安装时系统尚无记录也会尝试注册一次；注册失败不循环重试。源码／测试进程不操作真实登录项。
- macOS 根据系统事件的真实 Ctrl 按下时刻计算两秒，使用独立期限采样重验键鼠状态；Windows 在首个 Raw Input Ctrl make 事件开始计时，按住时以 16 ms 采样。两个平台启动时预热隐藏快捷窗口，显示时复用，减少首次唤起的冷初始化耗时。
- 保留启动时已按住需释放、睡眠／会话切换重置、其他键鼠取消、每次只触发一次和暂停状态不被打开窗口覆盖的约束。
