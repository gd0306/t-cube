# T-Cube 0.2 小巧透明版

按用户反馈，将原来的大尺寸深灰界面改成小巧透明立方体，并提供不依赖快捷键的移动把手。

## 变更

- 默认悬浮窗口从 350×350 点改为 164×190 点，包含底部把手；立方体可见区域约 110–120 点。菜单提供迷你、小巧、舒适三个尺寸。
- 面纹理保留真实 alpha，移除四块实色入口底板、重复“添加入口”文字和编号。透明表面配细边线与轻微暗边，图标与文字独立绘制。
- 调整观察角度以呈现三个面的立体形态。原有六面、四入口和正向吸附语义保持。
- 底部细把手直接移动窗口，松开后夹紧到可见屏幕并保存位置。立方体表面拖动仍旋转，Option 拖动仍可移动。
- 鼠标穿透判断包含把手，拖动期间保留事件接收。编辑窗口与 README 的操作提示已更新。
- 原有分组、入口和位置配置沿用，不重置用户数据。

## 验证

- 新透明测试在旧纹理上实测失败：背景 alpha 为 1.0；修改后背景 alpha 小于 0.3，内容仍有大于 0.8 的 alpha。
- 新把手测试先因缺少 MoveHandleView 失败；实现后，直接调用真实 NSPanel 的把手鼠标事件，确认无修饰键拖动会移动窗口、松开才回调保存、结束后清除拖动状态。
- 最终 `swift test --scratch-path .build/tests` 在 22:48:55 返回 0：20 项核心测试和 2 项原生界面测试全部通过。
- `bash scripts/build-app.sh` 成功生成 0.2.0 本地 release 应用；plist、严格签名验证、`git diff --check` 均通过。
- 实际启动最终应用，截图尺寸为 328×380 像素（Retina 对应 164×190 点），可见透明立方体、细边线、空位和底部把手。首次预览在白底上对比不足，已加强暗边和文字描边后重新构建、启动并检查。
- 对容器布局、拖动坐标、保存、穿透、透明材质与六面朝向进行了独立静态审查，无阻塞性问题。

## 验证限制

当前桌面自动化对新版悬浮面板的实际拖动仍返回 `AXError.notImplemented`。把手的事件处理和原生窗口位置改变已由原生测试验证，但真实鼠标手感、不同桌面背景、跨屏拖动和完整应用启动流程仍需手动验收。真实桌面透明效果也会随背景变化。
