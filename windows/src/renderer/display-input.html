如何获取输入代码？

T-Cube 自动检测已连接的显示器并读取当前输入代码，不读取全部可用值，也不会按型号猜值。VCP 0x60 是功能编号，不是要填写的端口值。

  1. 在显示器实体菜单开启 DDC/CI，连接并唤醒 Type-C 与 HDMI 两端主机。按名称和 DISPLAY 编号选择对应屏幕；同名时可暂时断开其他屏幕再刷新。
  2. 用实体菜单选中 Type-C。在当前显示画面的主机上打开 T-Cube「显示器输入源…」，选择该屏幕并点「刷新」，展开「设置输入源代码」，记下「当前代码」的十进制整数。
  3. 用实体菜单选中 HDMI，在 HDMI 活动主机上重复刷新并记下代码。不要在已经失去画面的主机上反复读取。
  4. 回到要配置的主机，填写两个实测、不同的代码（0–65535），点「保存代码」。每台主机分别保存，保存不会切换输入。
  5. 确认能用实体菜单切回后，点击 Type-C 或 HDMI 验证画面及回读。「无法确认」可能已经切走，请从当前活动主机或实体菜单切回。

无法读取？检查 DDC/CI、线缆、扩展坞和转接器，尝试直连并刷新。部分连接或显示器不支持输入源控制。未返回代码时不要猜值，使用实体菜单或咨询厂商。自动检测不代表硬件已验证兼容。
